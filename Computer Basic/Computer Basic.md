
# Computer Basics

## 1. Inside a Computer

Ein Computer besteht aus verschiedenen Hardware-Komponenten. Jede Komponente hat eine bestimmte Aufgabe.

### CPU – Central Processing Unit

- Das „Gehirn“ des Computers.
    
- Führt Berechnungen und Befehle aus.
    
- Je stärker die CPU, desto mehr Aufgaben können schnell verarbeitet werden.
    

### RAM – Arbeitsspeicher

- Temporärer Speicher.
    
- Speichert Daten, die gerade verwendet werden.
    
- Mehr RAM ermöglicht mehr gleichzeitig laufende Programme.
    

### SSD / HDD – Speicher

- Speichert Daten dauerhaft.
    
- **SSD:** schneller, leiser und moderner.
    
- **HDD:** langsamer, aber häufig günstiger bei großer Speicherkapazität.
    

### GPU – Graphics Processing Unit

- Verarbeitet Grafiken und Bilder.
    
- Wichtig für Gaming, 3D, Video und teilweise KI.
    

### Mainboard – Motherboard

- Verbindet die verschiedenen Hardware-Komponenten miteinander.
    
- CPU, RAM, SSD, GPU und andere Komponenten werden darüber verbunden.
    

### Netzteil – Power Supply Unit (PSU)

- Versorgt den Computer mit elektrischer Energie.

## 2. Internet Connection Types

Eine Internetverbindung ermöglicht einem Gerät den Zugang zum Internet.

### DSL

Internet über die Telefonleitung.

- Beispiel: ADSL, VDSL
    
- In Deutschland weit verbreitet.
    

### Cable

Internet über das TV-Kabelnetz.

- Kann hohe Geschwindigkeiten erreichen.
    

### Fiber Optic – Glasfaser

Internet über Glasfaserkabel.

- Sehr hohe Geschwindigkeit.
    
- Niedrige Latenz.
    
- Sehr gut für moderne Netzwerke.
    

### Mobile Internet

Internet über das Mobilfunknetz.

- 4G / LTE
    
- 5G
    
- Wird z. B. bei Smartphones verwendet.
    

### Satellite Internet

Internet über Satelliten.

- Kann auch in abgelegenen Gebieten genutzt werden.
    
- Höhere Latenz als bei vielen Kabel- oder Glasfaserverbindungen.
    

### Wi-Fi

Wi-Fi ist nicht dasselbe wie der Internetanschluss.  
Wi-Fi verbindet Geräte drahtlos mit einem lokalen Netzwerk.  
Der Router verbindet dieses Netzwerk normalerweise mit dem Internet.

## Wichtige Begriffe

**Hardware:** Physische Teile eines Computers.

**Software:** Programme und Betriebssysteme.

**CPU:** Verarbeitet Befehle.

**RAM:** Temporärer Arbeitsspeicher.

**SSD/HDD:** Dauerhafter Speicher.

**GPU:** Verarbeitung von Grafiken.

**Mainboard:** Verbindet Hardware-Komponenten.

**ISP – Internet Service Provider:** Unternehmen, das Internetzugang bereitstellt.

**Router:** Verbindet verschiedene Netzwerke und leitet Daten weiter.

**LAN – Local Area Network:** Netzwerk in einem begrenzten Bereich, z. B. Zuhause oder in einer Firma.

**WAN – Wide Area Network:** Netzwerk über größere geografische Entfernungen. Das Internet ist ein Beispiel für ein WAN.

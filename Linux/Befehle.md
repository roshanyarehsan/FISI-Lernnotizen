# Linux Befehle

## Grundlegende Befehle

| Befehl        | Funktion                                                        |
| ------------- | --------------------------------------------------------------- |
| `whoami`      | Zeigt den aktuellen Benutzer.                                   |
| `echo`        | Gibt Text aus.                                                  |
| `pwd`         | Zeigt den aktuellen Pfad.                                       |
| `ls`          | Listet Dateien und Ordner auf.                                  |
| `cd`          | Wechselt den Ordner.                                            |
| `cat`         | Zeigt den Dateiinhalt.                                          |
| find          | Sucht Dateien und Ordner.                                       |
| `grep`        | Sucht Text in Dateien oder Ausgaben.                            |
| ip a          | Man nutzt, wenn man die IP-Adresse wissen will                  |
| `mkdir`       | Erstellt einen neuen Ordner.                                    |
| `rmdir`       | Löscht einen leeren Ordner.                                     |
| `rm`          | Löscht Dateien (mit `-r` auch Ordner mit Inhalt).               |
| `cp`          | Kopiert Dateien oder Ordner.                                    |
| `mv`          | Verschiebt oder benennt Dateien und Ordner um.                  |
| `touch`       | Erstellt eine neue, leere Datei.                                |
| `cat`         | Zeigt den Dateiinhalt direkt im Terminal.                       |
| `less`        | Zeigt lange Dateien Seite für Seite (Beenden mit `q`).          |
| `clear`       | Leert den Bildschirm im Terminal.                               |
| `history`     | Zeigt die zuletzt eingegebenen Befehle.                         |
| `chmod`       | Ändert die Rechte einer Datei (lesen, schreiben, ausführen).    |
| `sudo`        | Führt einen Befehl mit Administratorrechten aus.                |
| `apt update`  | Aktualisiert die Liste der verfügbaren Programme und Versionen. |
| `apt upgrade` | Installiert die neuen Versionen der installierten Programme.    |
| `man`         | Zeigt die Anleitung (Handbuch) zu einem Befehl, z. B. `man ls`. |

## Shell-Operatoren

| Operator | Funktion                                                          |
| -------- | ----------------------------------------------------------------- |
| `&`      | Startet einen Befehl im Hintergrund.                              |
| `&&`     | Führt den zweiten Befehl nur aus, wenn der erste erfolgreich war. |
| `>`      | Leitet die Ausgabe in eine Datei um und überschreibt sie.         |
| `>>`     | Fügt die Ausgabe am Ende einer Datei hinzu.                       |
